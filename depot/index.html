Le dépôt APT d'Yggdrasil 1.0.1

Les machines Yggdrasil l'utilisent d'elles-mêmes (paquet yggdrasil-archive-keyring) : ygg update y prend les nouvelles versions des outils. Il est signé : APT refuse tout paquet que cette clé n'a pas signé. Sur une autre Debian 13 :

sudo curl -fsSLo /usr/share/keyrings/yggdrasil-archive-keyring.gpg https://naisora.github.io/YggdrasilOS/depot/yggdrasil-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/yggdrasil-archive-keyring.gpg] https://naisora.github.io/YggdrasilOS/depot trixie main" \
  | sudo tee /etc/apt/sources.list.d/yggdrasil.list
sudo apt update

Empreinte de la clé : D9E68E498E69C4AA5CE51ABB6390560730652DE6

Paquets : yggdrasil-archive-keyring, yggdrasil-base, yggdrasil-calamares, yggdrasil-desktop, yggdrasil-serveur, yggdrasil-tools.

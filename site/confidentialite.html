Confidentialité

En bref : ni ce site ni Yggdrasil ne recueillent de données sur toi. Pas de cookie, pas de mesure d'audience, pas de publicité, pas de télémétrie.

Ce site

  • Aucun cookie, rien d'enregistré dans ton navigateur, aucune mesure d'audience, aucun pixel de suivi. Les polices sont servies par le site lui-même, aucune n'est demandée ailleurs. Il n'y a donc pas de bandeau de cookies : il n'y aurait rien à accepter ni à refuser.
  • Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub reçoit l'adresse IP des visiteurs et la garde pour la sécurité de son service, comme il l'explique ; cela relève de GitHub et de sa déclaration de confidentialité.
  • Pour afficher les versions et leurs fichiers, l'accueil et la page des nouveautés demandent la liste des versions à l'API de GitHub (api.github.com), depuis ton navigateur, sans cookie ni identifiant : GitHub voit passer ton adresse IP, comme pour la page elle-même.
  • Les téléchargements se font chez GitHub (github.com et ses serveurs de fichiers), avec les mêmes règles.

Yggdrasil, le système

  • Pas de télémétrie : Yggdrasil n'envoie ni statistiques d'utilisation, ni rapports de plantage, ni identifiant de ta machine. Mímir, l'IA, tourne sur ta machine : tes questions et tes journaux n'en sortent pas.
  • De lui-même, en arrière-plan, le système ne contacte que des serveurs de mises à jour : les miroirs de Debian et le dépôt d'Yggdrasil (hébergé par GitHub, avec ce site), chaque jour, pour installer les correctifs de sécurité ; Flathub, pour les applications Flatpak ; le service de micrologiciels de Linux (LVFS), pour les mises à jour de firmware. Comme tout serveur, ils voient passer ton adresse IP.
  • Le reste n'arrive que si tu le demandes : le modèle de Mímir se télécharge chez Ollama quand tu fais pousser Vanaheim ; les notifications de Ratatoskr ne vont sur ton téléphone que si tu le relies (ratatoskr telephone), par ntfy.sh sur un canal au nom aléatoire, ou par ton propre serveur ntfy ; Bifröst télécharge les images de ses services, et les mods Minecraft sur Modrinth ; chaque monde installe ses logiciels depuis leurs propres dépôts.
  • Les applications que tu ouvres (Firefox, Discover, Steam, Discord, Spotify…) parlent à leurs propres services, selon leurs propres règles de confidentialité.

Tes droits

Le projet ne recueille ni ne conserve aucune donnée personnelle : il n'y a rien à consulter, rectifier ou effacer chez lui. Pour ce que GitHub traite (adresse IP, ton compte GitHub si tu ouvres une issue), adresse-toi à GitHub, selon sa déclaration de confidentialité. En France, tu peux aussi saisir la CNIL.

Une question ? Ouvre une issue sur GitHub. Les issues sont publiques : n'y mets rien de personnel, et relis les journaux avant de les coller (ils contiennent parfois des noms de machine ou d'utilisateur).
